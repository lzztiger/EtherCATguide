SSC软件安装

安装过程很简单，不再赘述。

新建工程

点击File->New

根据需要选择不同的配置

ethercat-master\ethercat-master\apps\ethercat_counter_foe_app\firmware\src\slave_stack\lan9255

Import成功后可以看到如下

点击OK，可以看到EtherCAT slave的配置信息

导入APP（EXCEL）文件

在Tool Application Import 导入应用文件

根据需要修改excel中变量的定义

import 进应用 sample_app的EXCEL，配置变量

点击OK

生成Slave Stack 代码

点击Create new Slave Files

可以在此选择地址，

esp是项目文件 ；

src是slave源码，路径尽可能简洁，不要包含中文；

ESI是slave配置的xml文件；
